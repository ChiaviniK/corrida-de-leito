# Skill: Auditoria de Reuso de Componentes

## Passos
1. Antes de criar um novo componente de UI, consulte o diretório de componentes comuns e design system.
2. Verifique se o componente existente atende à necessidade via extensão de propriedades (`props` opcionais ou slots/children).
3. Se um novo componente for indispensável, certifique-se de que ele respeite a acessibilidade e possa ser promovido ao design system compartilhado.
