# Runbooks Operacionais

Diretório destinado a procedimentos técnicos e operacionais do sistema de gestão de leitos.

- `runbook-migracoes.md`: Procedimentos para execução e reversão de migrations de banco de dados.
- `runbook-deploy.md`: Passos para deploy seguro, smoke tests e rollback.
- `runbook-incidentes.md`: Procedimentos de contingência para indisponibilidade ou lentidão.
