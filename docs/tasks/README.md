# Relatórios de Tarefas (Task Reports)

Nesta pasta são armazenados os relatórios gerados obrigatoriamente ao final de cada feature, conforme o padrão:
`docs/tasks/YYYY-MM-DD-[feature].md`

Cada relatório registra:
- Resumo do que foi implementado
- Arquivos criados e alterados
- Métricas de contexto (tokens com e sem Graphify)
- Testes e verificação
- Riscos remanescentes
